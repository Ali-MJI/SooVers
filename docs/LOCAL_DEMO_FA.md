# SooVers 0.4 — دموی آموزش

برای اجرای بستهٔ آماده، Node.js نسخهٔ ۲۲٫۱۳ یا جدیدتر نصب باشد. فایل ZIP را استخراج کن و در پوشهٔ `SooVers_Demo` اجرا کن:

```bash
node run.mjs
```

مرورگر را روی آدرس چاپ‌شدهٔ محلی، پورت 8080 باز کن. در Windows می‌توان `START_WINDOWS.bat` را اجرا کرد. نیازی به نصب وابستگی یا اتصال اینترنت برای اجرای دمو نیست. مستندات کامل مراجع، لینک خارجی دارند؛ یادداشت‌های درس داخل بسته‌اند.

راه جایگزین با Python:

```bash
python3 -m http.server 8080 --directory site --bind 127.0.0.1
```

مسیر ارائه: برج ← پذیرش و کارت دانشجو ← تعیین سطح ← مسیر یادگیری ← کلاس SOO ← میز کار ← آزمایشگاه و کاوش تجهیزات ← SOC ← مأموریت ATT&CK.

آزمون تعیین سطح ۸ سؤال دارد. نتیجه، درس‌های تمام‌شده و پیشرفت مأموریت در همان مرورگر ذخیره می‌شوند. لاگ‌ها و امتیاز پروندهٔ تمرینی برای همان بار اجرای صفحه‌اند. در گزارش JSON، هر دو بخش مشخص‌اند.

در پایانهٔ تمرین، `help` و سپس `cat auth.log` را اجرا کن. این پایانه روی دادهٔ آموزشی کار می‌کند؛ Shell سیستم‌عامل یا اتصال به ماشین مجازی نیست.

مدرس SOO یک کاراکتر با درس‌های ازپیش‌نوشته است. صدای فارسی به صدای نصب‌شدهٔ مرورگر وابسته است. حالت بدون صدا کامل قابل استفاده است. دمو نیاز به API هوش مصنوعی ندارد.

کنترل دسکتاپ: WASD / جهت‌ها، کشیدن برای نگاه، کلیک یا E برای انتخاب. حرکت لمسی در موبایل و دکمهٔ بازگشت به نقطهٔ ورود موجود است. دکمه‌های پایین هر فضا فعالیت‌های همان فضا را باز می‌کنند.

پوشهٔ `source` سورس همین نسخه است. فایل‌های `site` خروجی ساخت هستند. برای تغییر محصول سورس را تغییر بده و دوباره Build بگیر.

اتصال SOC به پروژه‌های واقعی، ماشین‌های ایزولهٔ آزمایشگاهی، حساب کاربری سروری و کلاس چندنفره در این بسته فعال نیستند. بخش آموزشی جدید هنوز آزمون هدست فیزیکی ندارد. توضیحات توسعه و استقرار در `source/docs` است.
